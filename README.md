PCB files for printing (supports a TMC 2208 chip controlled by arduino). Barrel jack power supply and a 4 terminal block


Plus, Arduino files in C language to drive the TMC 2208 motor driver chips with various functionalities. Includes several testing scripts for audio experiments. Plus some files that implement UART control with motor functions.
